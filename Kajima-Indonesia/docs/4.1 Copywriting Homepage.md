# 4.1 Copywriting Homepage: PT Kajima Indonesia

Step 4. Disusun 26 Okt 2026 dari:
- isi website existing (`Resources/Konten Website Existing.md` dan halaman detail proyek)
- struktur homepage di [1.3](../1.%20Plan/1.3%20User%20Journey%2C%20Sitemap%20%26%20Struktur%20Homepage.md)
- karakter di [3. Design Direction](../3.%20Design%20Direction/3.%20Design%20Direction.md)

**Catatan penyusunan:**
- Versi ringkas, dibuat bersamaan dengan desain Step 5 atas permintaan untuk segera melihat kedua opsi dalam bentuk desain.
- **Bahasa:** Inggris (sama dengan website existing). Versi Indonesia menyusul bila disetujui.
- **Pesan existing dipertahankan** di hero. Satu perbaikan tata bahasa: *"all kind buildings"* → *"all kinds of buildings"*.
- Bila copy berbeda antar-opsi, ditulis **A** (The Site Chief: tegas, teknis) dan **B** (The Senior Engineer: tenang, presisi). Selebihnya sama.
- Tanda **[konfirmasi]** berarti data perlu dicek klien.
